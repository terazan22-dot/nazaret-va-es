Nazaret Valero – Asistencia Virtual y Diseño Web

Acerca del proyecto

Sitio web profesional que presenta servicios de asistencia administrativa remota y diseño web dirigidos a contratistas, empresas de construcción y pequeñas empresas.

La plataforma combina apoyo administrativo y soluciones digitales para ayudar a las empresas a mejorar su organización, optimizar sus operaciones diarias y fortalecer su presencia en internet.

Servicios

- Elaboración de cotizaciones y presupuestos.
- Digitación de datos y gestión de Excel.
- Organización y gestión documental.
- Asistencia por correo electrónico y WhatsApp.
- Gestión de calendarios y citas.
- Diseño web y soluciones digitales.

Secciones del sitio web

- Inicio: Presentación y servicios principales.
- Sobre mí: Trayectoria profesional y experiencia.
- Servicios: Descripción de los servicios disponibles.
- Portafolio: Muestra de documentos administrativos y sitios web desarrollados.
- Cotización gratuita: Solicitudes de presupuestos y consultas sobre soluciones web.
- Contacto: Información de contacto y formulario de comunicación.

Diseño e identidad visual

Una interfaz limpia, elegante y profesional que incluye:

- Paleta de colores azul marino, dorado, blanco, marfil cálido y azul grisáceo.
- Tipografía elegante y distribución organizada.
- Tarjetas con bordes redondeados, sombras sutiles y detalles dorados.
- Diseño adaptable a diferentes dispositivos.
- Opciones de idioma en inglés y español.

Tecnologías

- HTML5
- CSS3
- JavaScript
